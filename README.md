# 🌲 Гостевой комплекс «ЭХО» (Echo Taiga Houses & Spa)

> **Портфолио-проект №2:** Высококонверсионный веб-сайт посуточной аренды загородных домов и глэмпинга с интерактивным календарем бронирования, расчетом банных спа-программ и интеграцией с Telegram.

📍 **Локация объекта:** Россия, Хабаровский край, г. Комсомольск-на-Амуре, ул. Комитетская, 1  
🗺 **Яндекс Карты:** [Организация «ЭХО» на картах](https://yandex.ru/maps/org/ekho/132315669502/?ll=136.910337%2C50.575678&z=17)  
🌐 **Онлайн Демо:** [https://garipov-ar.github.io/echo-houses-rental/](https://garipov-ar.github.io/echo-houses-rental/)

---

## 🎯 Цели и задачи проекта

1. **Прямые бронирования без комиссий агрегаторов** (экономия до 15-20% на комиссиях сторонних сервисов вроде Авито / Суточно.ру / Островок).
2. **Интерактивный переключатель двух домов:**
   - **A-Frame «Лесной Шалаш»** (до 4 гостей): второй свет, панорамные окна в пол, проектор с экраном для фильмов, виниловый проигрыватель, терраса с гирляндами.
   - **Семейное Шале «Большой Дом»** (до 10–12 гостей): 3 изолированные спальни, дровяной камин, обеденный стол на 12 персон, караоке-система, детская зона.
3. **Интерактивный калькулятор бронирования и расчета дат:**
   - Учет дифференцированных тарифов: будни (пн-чт) vs выходные (пт-вс, праздники).
   - Автоматическая скидка 10% при бронировании от 2-х суток.
   - Выбор банных спа-ритуалов (горячий сибирский чан с пихтой, русская баня на дровах с вениками, мангальный набор, 12л казан).
   - Расчет итоговой суммы, депозита и мгновенная отправка брони в Telegram / WhatsApp.
4. **Прозрачные правила и сервис:** время заезда/выезда, условия залога, режим тишины, Pet-Friendly статус.
5. **Локация и навигация:** интерактивная карта с точкой г. Комсомольск-на-Амуре, ул. Комитетская, 1.

## 🛠 Технологический стек

* **Frontend:** Next.js 15 (App Router), React 19, TypeScript
* **Стилизация:** CSS Modules, адаптивная верстка Mobile First, дизайн-система «Taiga Cozy & Warm Forest»
* **Иконки:** Lucide React
* **Валидация данных:** Zod
* **SEO & Микроразметка:** Schema.org (`LodgingBusiness`, `FAQPage`), OpenGraph
* **CI/CD:** GitHub Actions автоматический билд и деплой на GitHub Pages

## 🚀 Локальный запуск

```bash
# Переход в директорию проекта
cd echo-house-rental

# Установка зависимостей
npm install

# Запуск локального сервера разработки (http://localhost:3000)
npm run dev

# Проверка сборки статического экспорта
npm run build
```
